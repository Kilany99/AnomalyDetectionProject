# AnomalyDetectionProject
Smart system for anomaly detection and recognition using deep learning and computer vision.


If an anomaly event detected the scene well be sent to a web server then, to a mobile application of the security guard associated within a specific area according to the camera allocation

Used technologies: Html, CSS, JavaScript, jQuery, Reactjs, bootstrap, .net core MVC, .net REST API,SQL server, java for Android,and IIS express for local hosting.


This is the admin part of the application.
The admin of the system can :
1.Add, edit, update, delete clients.
2.Monitor camera streams.
3.Show full history of anomaly events and corresponding actions.
